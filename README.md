# 🌍 Heritage Treasures

Heritage Treasures is a data analytics and visualization project that explores UNESCO World Heritage Sites using Tableau. The project provides interactive insights into global heritage distribution, regional analysis, endangered sites, forecasting trends, and area coverage to support awareness and conservation efforts.
