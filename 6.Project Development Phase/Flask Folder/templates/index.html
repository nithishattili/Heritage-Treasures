About the Project

The Heritage Treasures project analyzes UNESCO World Heritage Sites across the globe. It explores cultural, natural, and mixed heritage classifications, regional distributions, endangered sites, and land area coverage using interactive Tableau dashboards.

  • 🌍 Global site distribution analysis
  • 🏛 Cultural, Natural & Mixed site insights
  • ⚠ Danger sites monitoring
  • 📈 Year-wise heritage trends & forecasting
  • 🗺 Area coverage analysis in hectares
